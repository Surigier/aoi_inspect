# 使用说明 —— AOI 实时在线 AI 质检系统

## 1. 环境

- Python 3.8+,PyTorch 2.4(CUDA 可选,有 GPU 则自动用)。
- 安装依赖:
```bash
pip install -r requirements.txt
```
(torch 随系统环境提供;requirements 含 timm / numpy / Pillow / open_clip_torch / gradio / pytest。)

## 2. 数据准备

公开数据集放到 `data/` 下(开发与泛化验证用,非评测必需):

- **MVTec AD**:解压到 `data/mvtec/<类别>/`,结构 `train/good/*.png`、`test/good/*.png`、`test/<缺陷>/*.png`。
- **MVTec LOCO**(逻辑/缺件):`data/_dl/mvtec_loco/<类别>/`(布局含 `test/logical_anomalies`、`test/structural_anomalies`)。

## 3. 运行测试

```bash
python -m pytest          # 全量单元/集成测试(37 passed)
```

## 5. 编程接口(评委评测入口)

赛题协议下,核心入口是适配器的 `fit_fewshot` + `predict`:

```python
import torch
from aoi.backbone import Backbone
from aoi.branches.texture_ad import TextureADBranch
from aoi.branches.structural_ad import StructuralADBranch
from aoi.multibranch import MultiBranchAdapter

bb = Backbone(pretrained=True, device="cuda")          # ImageNet 预训练冻结骨干
adapter = MultiBranchAdapter([
    TextureADBranch(backbone=bb, coreset_ratio=0.25),  # 外观/纹理
    StructuralADBranch(backbone=bb, grid_size=16),     # 缺件/逻辑/错位
])

# 现场迁移:100 张正常 + 30 张缺陷(均为 (3,H,W) [0,1] 张量列表)
adapter.fit_fewshot(normal_imgs, defect_imgs)

# 推理:输入 (1,3,H,W),返回 (BranchResult, 是否缺陷)
result, is_defect = adapter.predict(image_1x3xHxW)
print(result.score, result.defect_type, result.anomaly_map.shape)
```

辅助组件:
```python
from aoi.active_learning import ActiveLearningLoop   # 反馈闭环
from aoi.report import DefectReporter                # 冷路径缺陷报告(可注入 LLM)
from aoi.viz import overlay_heatmap                  # 热力图叠加
from eval.protocol import run_protocol               # 官方协议评测(AUROC/准确率/延时)

```

## 6. 视频输入(逐帧 + 时序平滑 + 事件聚合)

```python
from aoi.video import VideoDetector, read_video_frames

frames = read_video_frames("clip.mp4", size=320, stride=2)   # 懒加载 cv2
vd = VideoDetector(adapter, smooth_window=3, min_event_len=2) # adapter 须已 fit_fewshot
out = vd.process(frames)
# out["events"] = [(起始帧, 结束帧), ...];起始帧即"早期拦截"点
# out["frame_scores"] / ["smoothed_scores"] / ["frame_flags"] 为逐帧明细
```
时序平滑降低逐帧抖动,`min_event_len` 去除单帧误报尖峰,事件起始帧实现不良的早期拦截。

## 7. 输入约定

- 图像:`(3,H,W)` 或批量 `(B,3,H,W)`,float,范围 [0,1]。
- `predict`/各分支 `infer` 接收单图 `(1,3,H,W)`(批量请逐张调用)。
- `fit_fewshot` 接收 `(3,H,W)` 张量**列表**。
