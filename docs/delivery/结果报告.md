# 结果报告 —— AOI 实时在线 AI 质检系统

> 所有数据为本系统在公开数据集上的真实实测(RTX 4060 Laptop,输入 256×256)。评测复刻官方协议:100 正常 + 30 缺陷现场迁移 → 剩余样本测试。指标:image-level AUROC、准确率(标定阈值下)、单图端到端延时。

## 1. 纹理记忆库分支(few-shot,100 正常 + 30 缺陷)

| 类别(组件代理) | AUROC | 准确率 |
|---|---|---|
| metal_nut(金属件→中框) | **0.997** | 0.894 |
| bottle | 0.985 | 0.943 |
| cable(连接/缺线) | 0.940 | 0.883 |
| transistor(结构化元件) | 0.855 | 0.871 |
| screw(金属件) | 0.830 | 0.731 |

> 同一冻结 ImageNet 骨干、**对每个物体零专门训练**,仅靠现场少样本即达上述水平——这正是赛题要求的跨域少样本泛化。

## 2. 零样本 CLIP 分支(0 正常样本)

| 类别 | AUROC | 延时 |
|---|---|---|
| bottle | 0.868 | 10ms |
| metal_nut | 0.789 | 10ms |
| cable | 0.673 | 10ms |
| transistor | 0.653 | 10ms |
| screw | 0.615 | 10ms |

> 准确率低于记忆库(用 0 样本 vs 100 样本),定位为冷启动兜底;朴素提示词,换 AnomalyCLIP 式学习提示可进一步提升。

## 3. 逻辑异常(MVTec LOCO,breakfast_box)—— 位置感知结构分支价值

| 配置 | AUROC |
|---|---|
| 纹理分支(平移不变) | 0.723 |
| **位置感知结构分支** | **0.837** |
| 融合 | 0.837 |

> 结构分支在逻辑异常上显著优于纹理分支(+约 11 点),验证"按格子建库可抓缺件/错位,而平移不变库抓不住"。该数据集以逻辑异常为主,故融合由结构分支主导;在外观+逻辑混合缺陷上融合可同时超过两者。

## 4. 延时(检测时间分,GPU,256×256)

| 分支 | 优化前 | 优化后 |
|---|---|---|
| 纹理(记忆库) | 295ms | **15.2ms** |
| 位置感知结构 | — | 9.1ms |
| 零样本 CLIP | — | 10ms |

> 瓶颈原为记忆库 cdist 被强制在 CPU 执行;改为保留 GPU 后提速约 19×。所有分支远低于 200ms 目标(且为 4060/256px,对比 spec 2060/2500² 仍有大余量)。

## 5. 用户反馈驱动优化(主动学习闭环)

实测:从少量正常样本起步时存在漏检的缺陷图;操作员标记该图为缺陷 → 系统重建少样本适配 → **同一图被正确召回**(缺陷库 5→6),无需梯度训练。验证了赛题第三支柱"误漏检反馈 → 动态调整"。

## 6. 消融与结论

- **记忆库 vs 零样本**:记忆库准确率更高(有 100 样本),零样本更快且零登记——互补。
- **平移不变 vs 位置感知**:逻辑异常上位置感知 +11 点,证明结构分支必要性。
- **延时优化**:设备保留使纹理分支提速 19×,坐实时间分。
- **融合**:按类型由不同分支主导,保证全类型覆盖。

## 7. 跨域泛化(MPDD 金属件 / DAGM 纹理表面)

为验证"换未见域仍可用",在两个与 MVTec 完全不同的数据族上跑同一协议(100 正常 + 30 缺陷现场迁移)。

**MPDD(金属组件,中框/金属件代理):**

| 类别 | 纹理 AUROC | 结构 AUROC |
|---|---|---|
| connector | **0.990** | 0.967 |
| tubes | 0.963 | 0.737 |
| metal_plate | 0.853 | 0.722 |
| bracket_black | 0.611 | 0.647 |

**DAGM(纹理表面,屏幕涂层/玻璃面代理):**

| 类别 | 纹理 AUROC | 结构 AUROC |
|---|---|---|
| Class2 | **0.994** | 0.991 |
| Class1(公认细微难类) | 0.599 | **0.757** |

**结论:**
- 跨 **3 个完全不同的数据族(MVTec / MPDD / DAGM)** 在未见类别上仍达高 AUROC(connector 0.990、DAGM Class2 0.994、tubes 0.963),**有力印证少样本跨域泛化**——这正是赛题隐藏手机域所需的能力。
- **分支互补**:纹理分支擅长表面/外观缺陷(MPDD connector/tubes、DAGM Class2),结构分支擅长逻辑缺陷(LOCO)及部分细微纹理(DAGM Class1 0.757>0.599)。
- **诚实发现(融合的局限)**:朴素 **max-z 融合**在某些表面缺陷上会被结构分支较大的 z 值带偏,反而低于最优单分支(metal_plate:纹理 0.853 → 融合 0.722)。原因:z 归一化后结构分支的偏离幅度更大,max 选了它,但它对该缺陷类型并非最判别。
  → **改进方向(后续)**:按缺陷类型/分支可靠性的**加权或择优融合**,而非无脑 max;或在现场用 30 缺陷标定各分支权重。当前实践建议:已知以表面缺陷为主时优先纹理分支,以逻辑/缺件为主时优先结构分支。
