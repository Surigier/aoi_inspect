# 可解释性文档 —— 可自学习的 AOI 实时在线 AI 质检

## 1. 总体方案与设计依据

赛题评测协议为:提交代码后,评委用**未知产品(手机屏/电池/中框等)的 100 张正常 + 30 张缺陷**在其机器上现场迁移,再对 1000+ 测试图评测。该协议的本质要求是**跨未知域的少样本泛化**,而非在某一固定产品上训练。因此本方案的核心选型原则是:

> **目标域的"正常"在评测现场用 100 张正常图即时建模,而非依赖公开训练数据;公开数据只用于提供通用特征、开发方法与验证泛化。**

系统采用**热/冷双路径**架构:

- **热路径(被计时,要求 <200ms)**:仅放轻量专用检测模型(记忆库 / 位置感知 / CLIP),保证实时;
- **冷路径(不计时)**:放缺陷报告生成、操作员反馈、合成数据等,既拿可解释性/新颖性分,又不占用检测时间预算。

## 2. 各模块选型依据

### 2.1 纹理/外观异常 —— PatchCore 风格记忆库(`TextureADBranch`)
**为何选它**:无监督、训练-free。`fit_fewshot` 把 100 张正常图的 patch 特征存入记忆库,推理时取测试 patch 到记忆库的最近邻距离作异常分。"迁移"= 喂正常图进库,**无需梯度训练**,现场几秒完成、可复现——天然契合赛题的现场迁移协议。骨干用 ImageNet 预训练 `wide_resnet50_2`(冻结),其通用特征对自然图像(金属/玻璃/塑料/屏幕)即插即用。
**证据**:在从未专门训练的多个类别上,仅靠现场少样本即达 image-AUROC 0.83–0.997(见结果报告)。

### 2.2 零样本冷启动 —— CLIP 文本提示(`ZeroShotCLIPBranch`)
**为何选它**:连正常样本都没有时(冷启动)也能出结果。用"正常/异常"文本提示与图像嵌入的相似度,softmax 得异常概率。
**定位**:准确率弱于记忆库(它用 0 张样本 vs 记忆库 100 张),但**仅 10ms、零登记**,作为冷启动兜底与融合补充。

### 2.3 缺件/逻辑/错位 —— 位置感知记忆库(`StructuralADBranch`,核心创新)
**问题**:标准 PatchCore 把所有 patch 混进一个库(平移不变),**查不出"某位置该有的部件没了"**——因为缺件后该处变成背景,而背景特征在全局库里到处都有,距离反而小、被漏检。
**解法**:按空间格子**分别建库**(特征图自适应池化到 grid×grid,每格一个正常库)。某格测试特征远离**该格**正常库 = 该位置缺件/错位。**无监督、不需预定义部件、不绑定目标域**,契合泛化要求,直接服务赛题"组件状态/缺件/早期拦截"。
**证据**:MVTec LOCO(逻辑异常)上结构分支 0.837 > 纹理分支 0.723,证明抓住了纹理分支漏掉的逻辑缺陷。

### 2.4 尺寸偏差 —— 前景面积统计(`DimensionADBranch`)
量前景面积(偏离背景中位数的像素数)与正常面积分布比较,z 分越界即尺寸异常。轻量、无额外依赖。

### 2.5 多分支融合(`MultiBranchAdapter`)
各分支分数量纲不同,先按"正常分均值/方差"做 z 归一化,再取最大融合(任一分支报异常即异常),最后标定单一阈值。接口与单分支适配器一致,可直接用于评测。**价值**:不同缺陷类型由不同分支主导(外观→纹理、逻辑→结构),融合保证全类型覆盖的鲁棒性。

### 2.6 用户反馈驱动优化 —— 主动学习闭环(`ActiveLearningLoop`)
赛题必做支柱。操作员标记漏检/误检 → 样本加入对应集合 → 重跑 `fit_fewshot`(记忆库重建 + 阈值重标定,无需梯度训练)完成在线更新。实测:一张被漏检的缺陷图,经反馈后被正确召回。

### 2.7 冷路径 LLM 缺陷报告(`DefectReporter`)
从检测结果抽结构化事实(类型/分数/最可疑网格位置)生成中文缺陷报告;默认模板,**可注入 LLM** 生成更自然表述。位于冷路径,不影响检测计时。

## 3. 合成数据策略
轻量 Cut-Paste/Perlin 合成可在现场迁移时把 30 张缺陷扩充以提分(对应开集监督思路);重型 Diffusion 合成仅训练期离线、作可选新颖项。**核心三分支为无监督,不依赖合成数据**,合成仅为增益。

## 4. 为何不直接训练"手机缺陷检测器"
赛题以现场少样本 + 隐藏测试集 + 专家"泛化性"评分,**刻意防止过拟合目标域**。直接训练特定手机缺陷的监督检测器会在未见缺陷/产品上崩溃并失分。本方案坚持"现场少样本自适应 + 通用特征 + 相近材质公开集验证 + 合成缺陷侧面注入",以最大化泛化。
