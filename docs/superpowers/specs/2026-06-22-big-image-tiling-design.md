# 大图分块少样本检测(TiledFewShotDetector)设计

日期:2026-06-22 | 分支:big-image-tiling

## 背景与问题
赛题真实输入为 **2500×2500**,要求 2060 GPU **<200ms**(挑战 CPU<2s)。现有系统统一 resize 到 320,对 2500² 是 ~60× 下采样,**极小缺陷在特征层被抹掉**(我们 1024px 的测试集系统性高估了小缺陷精度)。整图高分辨率送 PatchCore 计算/显存不可行。

## 方法依据(文献)
- **Tiled Ensemble《Divide and Conquer》(arXiv 2403.04932,已入 Anomalib)**:高分辨率图切重叠块、**每块位置一个模型**、兼容任意 AD 模型,小缺陷数据集(VisA)增益明显。逐块串行→恒定显存(它优化内存)。**不做 few-shot**。
- **EfficientAD(WACV2024)**:小模型 2ms,启发"小骨干+实时"。
- 我们对论文的**两点改进**:① 扩展到 **few-shot**(论文没有,我们的差异化);② **块批处理换延时**(论文逐块省内存;我们 2060 显存够,目标是 <200ms);③ 图级聚合用 **top-k 均值**而非平均(对"2500²里单个小缺陷"更敏感,平均会稀释)。

## 架构
`TiledFewShotDetector`(包在现有分支外的大图前端,不改块内逻辑):
1. **切块**:2500² → 重叠块(tile=512, stride=448 → ~6×6)。
2. **批前向**:块打包过**小骨干 ResNet18**(timm,layers=(2,3))。
3. **记忆库**:`position_aware=False` 共享库(鲁棒/不赌对齐)| `True` 每块位置独立库(对齐件更强,论文做法)。两者均为配置开关,实测对比。
4. **块打分**:每块 patch 最近邻距离 top-k 均值(复用 MemoryBank)。
5. **图级聚合**:块分数 **top-k 均值** → 图分数;argmax 块给缺陷**位置**。
6. **阈值**:fit 时在图级正常/缺陷分数上用现有 `_calibrate`(max(bal,p98))。
7. **few-shot**:100 正常切块建库;30 缺陷切块算图级分数标阈值(MVP 先不做块级判别头——缺块级标签;后续可用 argmax 块作伪标签扩展)。

## 验证
- **效果**:合成 2500²(真实纹理铺满+贴小缺陷裁片)对比 **整图 resize vs 分块** 的小缺陷可分性(AUROC/分差)。
- **延时**:合成 2500² 实测分块 predict 的 GPU 延时(目标 <200ms)。
- **真实证据(后续)**:MVTec AD 2(注册下载,高分辨率+极小缺陷)/ MVTec-2K。
- **CPU<2s(后续)**:ResNet18 OpenVINO 导出。

## 范围与非目标
- 范围:大图分块前端 + 小骨干 + few-shot 适配 + 效果/延时验证。
- 非目标(本 spec 不含):色彩变化分支、合成缺陷生成、AHL 对齐、zero-shot——后续单独 spec。
